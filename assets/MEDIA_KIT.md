## Editorial Descriptions

### One Sentence

Awesome Loop Engineering is a field guide and implementation kit for recurring AI-agent systems, connecting 874 resources to 22 operational patterns, 22 loop contracts, 8 runtime starters, an interactive atlas, and a structured dataset.

### Short Paragraph

Awesome Loop Engineering maps how recurring AI agents discover work, act with scoped tools, pass independent verification, preserve state, and decide whether to retry, hand off, or stop. Readers can explore 874 papers, official docs, tools, benchmarks, and guides, then build from 22 patterns, 22 schema-checked contracts, and 8 runtime starters.

### What Distinguishes It

- It connects research evidence to patterns, contracts, and executable or copy/paste starters.
- It separates model recurrence, one-task agent execution, harnesses, and recurring operations instead of treating every loop as the same mechanism.
- It makes external verification, durable state, budgets, escalation, and exit visible.
- It exposes the resource map as CSV, JSONL, and Parquet through Hugging Face.

## Usage

- Use the editorial cover as composed; do not crop individual layers or separate the labels from the stack.
- Use the social preview for link cards that need current project statistics.
- Use the logo family when the project name appears separately in adjacent text.
- Preserve the semantic layer order: Prompt, Context, Harness, then Loop.
- Follow the clear-space, color, and mark rules in the [brand system](BRAND.md).
